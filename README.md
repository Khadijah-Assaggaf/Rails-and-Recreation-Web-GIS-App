# Interactive Web GIS Locator & Spatial Analysis App

## Overview
An interactive Web GIS applications project developed The app leverages ArcGIS Instant Apps on ArcGIS Online to enable multi-criteria spatial search, proximity buffer analysis, and navigation routing for recreational facilities and rail stations (Rails and Recreation Locator).

## Features & Capabilities
- **Web App Configuration:** Built and configured a dynamic web application using ArcGIS Instant Apps templates.
- **Proximity & Buffer Search:** Configured spatial search capabilities allowing users to find interest points within a customizable buffer distance.
- **Routing & Directions:** Integrated network routing tools to calculate optimal travel time and driving/walking directions between selected locations.

## Technical Stack & Tools
- ArcGIS Instant Apps
- ArcGIS Online
